
# TP1-PoweChess

## Descripción
TP1-PoweChess es un juego de ajedrez implementado en Java utilizando JavaFX. Este proyecto incluye características de poderes especiales para las piezas, ofreciendo una experiencia de juego diferente.

## Requisitos

- **Java JDK 17.0.6** Debe ser compatible con JavaFX 17.0.6.
- **Apache Maven 3.6.3** o superior
- **JavaFX** (incluido en las dependencias del proyecto)

## Instalación

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/WariasGit/TP1-Algoritmos3-Paradigmas-De-Programacion-FIUBA.git
   cd TP1-PoweChess

-Configura Maven:
Debe apuntar a la versión de Java adecuada. Poder verificar la versión de Maven ejecutando:
mvn -v

-Se puede verificar la version de java instalada ejecutando:
java -version

2. **Ejecución**

Para ejecutar el proyecto, utiliza los siguientes comandos:
mvn clean install
mvn javafx:run

Problemas Comunes
Versiones de Java: Si tenes problemas con la versión de Java, asegúrate de que estás usando Java 17.0.6 instalado.
